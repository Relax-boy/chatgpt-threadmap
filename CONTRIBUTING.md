# Contributing

Issues and pull requests are welcome.

1. Fork and clone the repository.
2. Make a focused change in `src/content/`.
3. Run `npm test`.
4. Verify the unpacked extension on `https://chatgpt.com/` in both light and dark mode.
5. Open a pull request describing the behavior before and after your change.

Please do not include conversation data, account information, or screenshots containing private content.
